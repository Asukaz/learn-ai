Base Model: The Token-by-Token Prediction Machine

A base model generates text by predicting one next token at a time.

The core loop

Context → probability distribution → selected token → updated context → repeat. The model does not retrieve a prewritten continuation. At each decoding step it estimates which token is plausible next.

What to notice

The continuation can look purposeful even though the mechanism shown here is local: each step consumes the full context and produces probabilities for the next token. Modern systems add instruction tuning, tools, retrieval, memory, and other layers on top of this base behavior.
