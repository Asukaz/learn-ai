GPT's Leap

From local windows and fading memory to attention and causal generation.

Why the architecture mattered
The key shift was not “more words.” It was a better way to use context at scale.

Use one English sequence below to compare four model families. The point is conceptual: each architecture exposes a different pattern of information to the model.

CNN: a fixed local window

A convolution sees only a local neighborhood at each step. A relationship can be missed when the relevant tokens fall outside the current window.

RNN: earlier information fades as the sequence grows

An RNN carries information forward through a hidden state. In long sequences, early information can become difficult to preserve and learn from.

BERT: every token can use context on both sides

Click a token. The highlighted sequence shows that a bidirectional encoder may use tokens both before and after that position. This is excellent for understanding and representation learning, but BERT was not designed as a left-to-right text generator.

GPT: causal attention + next-token generation

The engineer reviewed the model report before the meeting ▌
For the next token, GPT can attend to the tokens already available on the left, but not future tokens. After one token is generated, it becomes part of the context for the following step.
What GPT changed

Transformer attention made long-range context far easier to model in parallel, while causal language modeling made generation natural. Large-scale pretraining then let one general model transfer across many downstream tasks instead of training a separate model from scratch for each task.
